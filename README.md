# String Art Generator

Веб-приложение на Next.js для генерации макетов string art. Математическое ядро и расчет v4/v5/v6 выполняются в браузере, без отправки фото на сервер.

## Как работает

1. Загружает исходное изображение.
2. Позволяет кадрировать фото зумом и перетаскиванием. Предпросмотр показывает оригинальный кадр, а для расчета нитей строится внутренняя тональная карта с мягким усилением контуров.
3. Расставляет пронумерованные точки по окружности.
4. В режиме v4 выбирает следующую линию по остаточной оптической плотности.
5. Стабильный режим v5 воспроизводит математическое ядро из коммита `3423ba4`: дискретные линии, масштабы `560`, `280` и `140` пикселей и прежний баланс маршрута.
6. Экспериментальный режим v6 содержит все последующие улучшения: субпиксельную модель толщины нити, откалиброванный баланс маршрута и отдельную локальную замену слабых участков.
7. Выдает предпросмотр и инструкцию сборки: последовательность соединения точек.

По умолчанию используется стабильный v5, нить `0.19 мм`, `240` точек, `4500` линий и размер картины `47 см`.

Ядра v5 и v6 изолированы друг от друга, а стабильная последовательность v5 закреплена регрессионным тестом. Локальная замена слабых участков не запускается автоматически и недоступна в v5. Для готового v6-макета появляется отдельная кнопка `Улучшить участки`; после обработки можно вернуть исходную последовательность без повторной генерации.

Расчет режимов v4/v5/v6 выполняется в Web Worker. Интерфейс остается отзывчивым, прогресс приходит пакетами, а кнопка `Стоп` сразу завершает worker и сохраняет уже построенную часть инструкции.

## Архитектура

- `components/StringArtGenerator.jsx` собирает React-интерфейс из рабочей области и панели настроек.
- `components/useStringArtController.js` управляет mount/unmount контроллера в жизненном цикле React.
- `app.js` экспортирует `mountStringArtApp(root)`, хранит состояние текущего расчета и при cleanup снимает все DOM-listeners и завершает активный worker.
- `core/` содержит независимые расчеты маршрута и форматирование схем.
- `workers/optical-worker.js` выполняет тяжелый расчет v4/v5/v6 вне основного UI-потока.
- `static-entry.js` сохраняет запуск прежней страницы `index.html` без React.
- `/build` открывает режим пошаговой сборки с голосом, паузой, скоростью и восстановлением прогресса из IndexedDB.

Такое разделение безопасно для React Strict Mode: повторный mount не создает дублирующиеся обработчики событий.

## Запуск Next.js

Нужен Node.js `20.9` или новее и pnpm.

```bash
pnpm install
pnpm dev
```

Затем откройте адрес, который напечатает Next.js, обычно `http://localhost:3000/`.

Production-сборка и тесты:

```bash
pnpm build
pnpm test
```

## Статическая версия

Прежняя версия сохранена как резерв и по-прежнему запускается обычным локальным сервером:

```bash
python3 -m http.server 5174
```

Затем откройте `http://localhost:5174/`. Next.js и статическая версия используют одно ядро и один Web Worker.

Для качественного портрета используйте `240` точек и `4500` линий. Если нужно быстро проверить механику, временно ставьте `180-240` точек и `800-2000` линий.

По умолчанию используется `240` точек и размер картины `47` см. После загрузки фото его можно двигать мышью/тачем на правом предпросмотре и масштабировать ползунком `Зум фото` или колесом мыши.

## Сравнение схем

Показатели маршрута двух TXT-схем можно сравнить командой:

```bash
node tools/compare-schemes.mjs reference.txt candidate.txt
```

Скрипт проверяет среднюю длину перехода, распределение точек и направлений, повторные хорды, параллельные линии и немедленные возвраты.
